# 拾光学习本

拾光学习本是一款面向校园学习场景的轻量化个人学习工作台，包含学习计划、每日打卡、进度可视化、三问复盘、课程管理和数据备份功能。

## 使用方式

直接打开 `index.html` 即可使用。网站不需要服务器或数据库，学习记录保存在当前浏览器的本地存储中。

## GitHub Pages

将本目录中的所有文件上传到公开仓库的 `main` 分支根目录，然后在仓库设置中选择 `Pages`，将部署来源设为 `Deploy from a branch`，分支选择 `main` 和根目录 `/`。

## 数据说明

- 网站不会上传学习数据。
- 更换浏览器或设备后，数据不会自动同步。
- 建议定期在个人设置中导出 JSON 备份。
