# 拾光学习本

面向财务管理专业的个性化学习工作台，围绕“统计学、商务英语3、中级财务会计Ⅱ”三门课程，提供任务计划、完成打卡、学习时长与进度可视化、每日复盘、数据导入导出等功能。

## 使用方式

- GitHub Pages：公开访问，无需登录。
- 本地使用：下载发布包后直接打开 `index.html`。
- 数据仅保存在当前浏览器的本地存储中，不会上传服务器。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式界面样式
- `core.js`：数据模型与本地存储
- `app.js`：界面渲染与交互逻辑
- `.nojekyll`：GitHub Pages 静态站点标记
